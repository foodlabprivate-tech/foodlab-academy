# Foodlab Academy

## Фото тех.карт — обязательный шаг перед переносом
Фото блюд хранятся в браузере того компьютера, где их загружали, и в архив
сами не попадают. Чтобы они уехали вместе с сайтом:

1. На своём компьютере: Админка → Фото продуктов → «Скачать папку с фото (ZIP)»
2. Получится архив foodlab-photos.zip: внутри папка photos с настоящими
   файлами фото и маленький card-photos.js со списком путей
3. Распакуйте архив в папку сайта — рядом с index.html должны лечь
   card-photos.js (заменить заглушку) и папка photos
4. Проверка: откройте photo-check.html — страница покажет, что нашлось,
   и что делать, если фото не видно. Вход для неё не нужен

Повторяйте шаг после того, как добавили новые фото в карты.

Кнопка «Старый способ: один файл» кладёт все фото внутрь card-photos.js
(50+ МБ). Работает, но файл тяжёлый — берите её только если папку photos
разложить некуда.

## Посмотреть без хостинга
Распакуйте архив целиком и откройте index.html двойным кликом.
Важно: держите все файлы в одной папке — сайт работает как есть, без интернета
(шрифты в офлайне заменятся на системные, на работу это не влияет).

Результаты в таком режиме хранятся в браузере того, кто смотрит.

# Как выложить сайт

## Что залить
Всю папку целиком, в корень хостинга. Точка входа — index.html.
Обязательные файлы рядом: support.js, data.js, questions.js, image-slot.js,
cards.json, image-slots.state.json, card-photos.js, папки img/ и photos/
и все файлы «Тех.карта - ....dc.html».

Подойдёт любой статический хостинг: Netlify, Vercel, GitHub Pages, обычный FTP.

## Первый вход
Готовы два аккаунта:
- admin / admin — админ, видит панель управления
- povar / povar — сотрудник, для проверки обычного кабинета

Сразу зайдите в Админка → Сотрудники, смените пароль администратора
и удалите тестового повара, когда закончите проверку.

## Как сотрудник получает доступ
Админка → Сотрудники: имя, логин, должность, роль. Поле пароля оставьте пустым —
система выдаст код приглашения из шести знаков. Передайте код сотруднику.

Сотрудник: главная → язык → «У меня код приглашения» → вводит код и придумывает
себе пароль. Код после этого сгорает, дальше вход по логину и паролю.

Забыл пароль: в списке сотрудников кнопка «Сбросить пароль кодом» — выдаётся
новый код, старый пароль перестаёт работать.

Роли: сотрудник (обучение и тест), су-шеф (плюс админка), админ (всё).

## Общая база результатов
Без базы всё работает, но результаты видны только в том браузере, где проходили тест.
Чтобы видеть всех в одной панели:

1. Создайте бесплатный проект на supabase.com
2. SQL Editor → вставьте целиком supabase-schema.sql → Run
3. Settings → API → скопируйте Project URL и anon public key
4. В сайте: Админка → Настройки → База данных → вставьте оба поля →
   «Подключить и проверить»

После подключения результаты, сотрудники, настройки и правки вопросов хранятся
в базе и видны со всех устройств. Кнопка «Вернуть локальный режим» отключает базу.

## Обновление сайта по кнопке
Работает, если сайт на Netlify подключён к Git-репозиторию (не drag-and-drop ZIP).

1. Netlify → проект → Site configuration → Build & deploy → Build hooks →
   Add build hook → скопируйте URL
2. Сайт: Админка → Настройки → Обновление сайта → вставьте URL →
   «Запомнить ссылку»
3. Дальше обновление в один клик: «Синхронизировать сайт». Netlify выкладывает
   новую версию за минуту-две, прогресс виден в Netlify → Deploys

Кнопка перекладывает на сайт то, что лежит в репозитории и в базе. Фото блюд и
правки тех.карт без подключённой базы остаются в браузере — панель об этом
предупреждает прямо в блоке.

## Маршрут пользователя
index.html (выбор языка) → логин и пароль → должность (только при первом входе)
→ личный кабинет. Тех.карты и стандарты доступны только после входа.

## Что где
- index.html — выбор языка
- Академия.dc.html — вход, выбор должности, кабинет, каталог карт, программа, прогресс, тренажёр
- i18n.js — переводы интерфейса (RU / ID / EN)
- Тестирование - Завтраки.dc.html — тест, 10 вариантов
- Стандарты - SOP.dc.html — три SOP
- Админка.dc.html — панель управления
- questions.js — банк вопросов (правится и через админку)
- data.js — работа с базой
